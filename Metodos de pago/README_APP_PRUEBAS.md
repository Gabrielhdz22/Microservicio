# Aplicación de escritorio de pruebas

La aplicación es una interfaz sencilla en Python/Tkinter para probar el Microservicio de Métodos de Pago.

## Ejecutar

Usa `INICIAR_PRUEBAS.bat`. No necesitas iniciar manualmente el microservicio antes.

## Pestañas

- **Resumen:** estado y estadísticas generales.
- **Métodos de pago:** crear, consultar, habilitar/deshabilitar y eliminar.
- **Pagos:** registrar, consultar y eliminar pagos de prueba.
- **Respuesta API:** muestra el JSON de la última operación.

## Seguridad de la demostración

Los pagos son únicamente de prueba. No se manejan datos reales de tarjetas ni se realizan cargos.
